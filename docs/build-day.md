# День сборки

Порядок такой: проверить детали мультиметром, собрать, проверить питание, прошить, подключить приложение, сделать первую серию записей. Если что-то не так, по каждому сбою есть раздел ниже.

Файлы `telehaptic.uf2` и `telehaptic.apk` лежат в релизе [latest](https://github.com/ivan-kalachikov/telehaptic/releases/tag/latest).

## 1. До пайки: детали по отдельности

Мультиметр в режиме сопротивления. Детали без питания.

| Что | Где мерить | Ожидаемо | Если нет |
|---|---|---|---|
| Нет замыкания в модуле GY-271 | VCC — GND | не меньше сотен Ом, не ноль | модуль неисправен, берите запасной |
| Подтяжки на GY-271 | SDA — VCC и SCL — VCC | несколько кОм; источники называют 2,2 и 4,7 кОм | «обрыв» (OL) — подтяжек нет: нужен резистор 4,7 кОм от SDA и от SCL к 3,3 В на этом канале |
| Подтяжка RST на мультиплексоре | RST — VIN | порядка 10 кОм | обрыв — подтяжки нет: соедините RST с VIN проводом |
| Адрес мультиплексора | перемычки A0, A1, A2 | не запаяны (адрес 0x70) | — |
| Батарея | красный — чёрный провод | 3,7–4,2 В | ниже 3,5 В — сначала зарядите от XIAO по USB |
| Выключатель | в разрыве плюса батареи | вкл — 0 Ом, выкл — обрыв | — |

Сфотографируйте маркировку чипа на каждом GY-271. Если прошивка опознает не тот чип, по фото я разберусь быстрее.

## 2. После пайки, без батареи

| Проверка | Ожидаемо |
|---|---|
| 3V3 — GND на XIAO | не ноль (единицы Ом и ниже — замыкание, не включать) |
| Прозвонка: D4 → SDA мультиплексора, D5 → SCL | 0 Ом |
| SD0/SC0 → SDA/SCL датчика 1 (сторона указательного), SD1/SC1 → датчик 2 (сторона мизинца) | 0 Ом, SDA не перепутан с SCL |
| D2 → SIG мотора | 0 Ом |
| 3V3 → VIN мультиплексора, VCC обоих GY-271, VCC мотора; все GND вместе | 0 Ом |

Оба магнитометра должны стоять в одной ориентации осей: стрелки X/Y на платах смотрят в одну сторону.

Расстояние между датчиками меряется от центра одного чипа до центра другого, в мм. Его спросит приложение.

## 3. Первое включение по USB, батарея отключена

Подключите XIAO кабелем к компьютеру или к зарядке.

| Где мерить (относительно GND) | Ожидаемо |
|---|---|
| 3V3 на XIAO | ≈ 3,3 В |
| VIN мультиплексора, VCC датчиков, VCC мотора | ≈ 3,3 В |
| SDA и SCL (D4, D5) в покое | ≈ 3,3 В. Около 0 В значит замыкание или перепутанные провода |
| SD0, SC0, SD1, SC1 в покое | 3,0–3,3 В. Около 0 В — нет подтяжек или замыкание на этом канале |

Если на модуле GY-271 стоит свой стабилизатор, на его выходе будет чуть меньше 3,3 В. Чипу QMC5883P хватает от 2,5 В. Схему модуля найти не удалось, поэтому напряжение надо именно измерить, не предполагать.

## 4. Прошивка

1. На компьютере скачайте `telehaptic.uf2` из релиза.
2. Подключите XIAO кабелем USB-C. Кабель должен передавать данные, а не только заряжать.
3. Дважды быстро нажмите крошечную кнопку reset. Появится диск `XIAO-SENSE`.
4. Скопируйте на него `telehaptic.uf2`. Диск исчезнет сам: плата перезагрузилась с новой прошивкой.

Диск не появился:
- нажимайте быстрее, два нажатия за полсекунды;
- возьмите другой кабель.

**Проверка без телефона, по желанию.** Откройте USB-порт XIAO в любом терминале на скорости 115200, например `screen /dev/ttyACM0 115200` на Linux. Должны появиться строки:

```
FW 0.1.<номер сборки>
BOOT reason=power_on
SCAN begin mux=yes
SCAN ch0 0x2C QMC5883P mag1
SCAN ch1 0x2C QMC5883P mag2
SCAN ch2 EMPTY HINT_PULLUPS
SCAN end mags=2
IMU ok LSM6DS3TR-C
CFG rate=100 range=30 osr=8/8 n=2 imu=1 mag1=QMC5883P@ch0,1000 mag2=QMC5883P@ch1,1000
LIVE mag1_uT=… mag2_uT=… bat_mv=…
```

`SCAN ch2 EMPTY` — это нормально, канал 2 запасной.

Если скан запустился раньше, чем открылся терминал, нажмите reset один раз. Скан повторится, а плата не уйдёт в режим прошивки.

## 5. Телефон

1. На телефоне откройте страницу релиза, скачайте `telehaptic.apk`, разрешите установку из этого источника.
2. Откройте приложение и нажмите «Разрешить»: нужны «Устройства поблизости» и уведомления. Затем «Найти и подключить капсулу».
3. На главном экране должно быть:
   - «Подключена»;
   - «Оба датчика на месте»;
   - примерный заряд, если подключена батарея.
4. Меню ⋮ → **Диагностика**:
   - **Скан шины.** Мультиплексор найден, на каналах 0 и 1 по QMC5883P, канал 2 — «датчика нет».
   - **Поле.** Без магнита модуль поля |B| у каждого датчика — десятки мкТл: это поле Земли плюс собственные смещения датчика. Поднесите магнит — значения меняются; ближний к магниту датчик меняется сильнее. Если стоит «НАСЫЩЕНИЕ», магнит слишком близко для выбранного диапазона.
   - **Поток.** Реальная частота около 100 Гц, потери за 10 с около 0%.
   - **Мотор.** Нажмите «100 мс» — капсула вибрирует, поле на время импульса сдвигается. Если после импульса капсула переподключается, а в Диагностике изменилась причина запуска (`BOOT`), мотор просаживает питание. Сообщите мне.
5. **Батарея.** Подключите батарею, включите выключатель, отсоедините USB. Сравните напряжение батареи по мультиметру с «Батарея» в Диагностике. Расхождение больше 0,05 В пришлите мне: это проверка делителя 1 МОм / 510 кОм по схеме.
6. Меню ⋮ → **Настройки**:
   - магнит и расстояние между датчиками;
   - токен GitHub;
   - «Проверить доступ».

**Токен GitHub:** github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
- Repository access: Only select repositories → `ivan-kalachikov/telehaptic`.
- Permissions → Repository permissions → Contents: Read and write.

Токен вставляется в Настройках один раз.

## 6. Если датчик не найден

Приложение пишет причину словами. Что делать по каждой:

| Сообщение | Что проверить |
|---|---|
| «Шина I2C не работает: линия SDA (SCL) прижата к земле» | Замыкание D4/D5 на GND, перепутанные провода, модуль подключён наоборот. Прошивка в этом случае на шину ничего не шлёт, плата не зависнет |
| «Мультиплексор не ответил, ищу датчики прямо на шине» | VIN, GND, SDA, SCL мультиплексора. Соедините RST с VIN. Перемычки A0–A2 не должны быть запаяны |
| «Канал N: датчик не отвечает. Проверьте провода SDN/SCN и подтяжки» | Провода этого канала: SDA с SDA, SCL с SCL; VCC и GND модуля; подтяжки (раздел 1). Поменяйте два модуля местами: если ошибка переехала, дело в модуле, если осталась на канале — в проводах. Запасной модуль можно поставить на канал 2 |
| «Канал N: неизвестный чип по адресу 0x…» или «HMC5883L» | Пришлите мне фото чипа и строку скана из Логов: допишу поддержку |
| «Канал N: QMC5883L» | Ничего делать не надо: прошивка работает и с ним, только диапазон до ±8 Гс |
| «Капсула не найдена» | Плата включена (USB или выключатель), Bluetooth телефона включён, капсула рядом. Нажмите reset и снова «Подключить» |
| «На связи, но данные не идут» | Выключите и включите капсулу. Если не помогло — меню ⋮ → Логи → «Отправить в репозиторий» и напишите мне |

После исправления проводки нажмите в Диагностике «Пересканировать». Перезагружать плату не нужно.

## 7. Первая серия записей

Меню ⋮ → **Эксперименты**. Перед каждой записью приложение проверит, что капсула на связи и оба датчика на месте.

1. **Калибровка.** Без магнита. 10 с кисть неподвижна, капсула пять раз вибрирует. Потом 40 с медленно вращайте кисть во все стороны.
2. **Клавиши**, «Рука на столе ребром». Магнит на ногте. Около 4 минут.
3. Снимите капсулу и наденьте снова. **Клавиши**, «Рука на столе ребром», отметка «После повторного надевания».
4. **Клавиши**, «Рука опущена вдоль тела».

Запись без магнита — потом, если первые результаты хорошие.

С токеном каждая запись сама уходит в `data/` репозитория, и я сразу запускаю анализ.

**Частота: 100 или 200 Гц, решение за вами.** Переключатель в Диагностике → «Настройки датчиков», действует до перезапуска капсулы.
- 200 Гц дают вдвое больше точек акселерометра в момент касания. Это нужно, чтобы проверить, виден ли толчок.
- 100 Гц — как на стенде, прямое сравнение.
